## 验证范围

- Windows/macOS：远端完整 Qt 测试、单元测试、编译检查与打包；具体结果以对应提交的 Actions 为准。
- 本地：下载正常保存、截断、错误页面、摘要不匹配、取消、目录创建和原文件保护，使用本地 HTTP 服务验证，不下载模型。
- 既有回归：预设加载、删除/排序，便携路径，动态目录和平台资产配对，日志格式化，GPU 索引/UUID/同名设备与无 PCI ID 映射。
- NVIDIA 索引与 UUID 查询曾在本机验证；没有启动额外模型计算。AMD/多 GPU、macOS 实机、在线工作区和历史 OpenSSL 故障明确保留未验证。

GPU UUID 路由依据：[NVIDIA CUDA 环境变量文档](https://docs.nvidia.com/cuda/cuda-programming-guide/05-appendices/environment-variables.html)。
